# Changelog

## 1.0.0

First release of anki-flashcards in this catalog. This skill replaces generate-flashcards and anki-export.

Both replaced skills shipped 1.0.0 as their first catalog release. generate-flashcards covered card generation. anki-export covered `.apkg` export.

The 80/20 concept filter still runs before priority and depth. The vividness rule still asks for a dramatic example and for a card the learner feels.
